# Healthcare ES + MCP + Agent UI — POC Plan

## Context

The user is building a local proof-of-concept that lets an AI agent answer questions about healthcare data stored in ElasticSearch, **without exposing PHI/PII to the LLM**. The MCP server is the trust boundary — every tool result is redacted before the agent sees it. The role-based filtering tier is deferred to production; the POC's redaction layer must be structured so that role plumbing can be added later without rewriting tools.

Three components: (1) ElasticSearch as data store, (2) Python MCP server enforcing PHI redaction, (3) FastAPI + HTMX agent UI that runs the Anthropic tool-use loop and acts as the MCP client.

## Decisions locked in

- **MCP server**: Python, `mcp[cli]` SDK using `FastMCP` (`from mcp.server.fastmcp import FastMCP`)
- **Data store**: ElasticSearch 8.13.4 in Docker, single-node, security disabled (local only)
- **LLM**: Anthropic API direct, model `claude-sonnet-4-6`, key via `ANTHROPIC_API_KEY` env var
- **Agent UI**: FastAPI + Jinja2 + HTMX (no React/Next.js)
- **Package manager**: `uv` (single `pyproject.toml`, console scripts for each entrypoint)
- **MCP transport**: stdio — FastAPI lifespan spawns MCP server as subprocess
- **PHI strategy**: redact at MCP boundary using Microsoft Presidio for free text + explicit structured-field rules; single `Redactor.redact(doc, role=None)` interface so role-based filtering can be added later

## ElasticSearch design

**Two indices** with realistic healthcare PHI:

- **`patients`**: `patient_id` (MRN like `MRN-000123`), `ssn`, `first_name`, `last_name`, `dob`, `address` (street/city/state/zip object), `phone`, `email`, `insurance_id`
- **`encounters`**: `encounter_id`, `patient_id` (FK), `provider_name`, `encounter_date`, `diagnoses[]` (ICD-10-like `{code, description}`), `note` (free text — **deliberately embeds patient name, DOB, phone in narrative** so Presidio is actually tested)

**Seed**: Faker with `seed_instance(42)`. ~500 patients × 1–5 encounters each. Note templates pick from ~10 narrative stubs that interpolate real PHI.

## MCP tools

All return JSON, post-redaction. Schemas auto-generated by FastMCP from type hints.

| Tool | Input | Returns (post-redaction) |
|---|---|---|
| `search_patients` | `query: str`, `limit: int = 10` | `[{patient_id, age_bucket, city, state}]` — names dropped |
| `get_patient` | `patient_id: str` | single patient: SSN removed, DOB→age bucket, phone/email masked, address→city+state only |
| `search_encounters` | `patient_id: str \| None`, `q: str \| None`, `limit: int = 10` | `[{encounter_id, patient_id, encounter_date, provider_name, diagnoses}]` |
| `get_encounter_note` | `encounter_id: str` | `{encounter_id, note_redacted}` — Presidio-anonymized free text |

## Redaction flow (the heart of the POC)

Inside every tool, **after** the ES query, **before** the return:

1. `Redactor.redact(doc, role=None)` is the single public entry point.
2. `structured_rules.apply(doc)` — drop SSN, bucket DOB to 10-year age range, keep MRN (the agent needs it as a join key), mask phone to last-4, mask email to `***@domain`, address to city+state.
3. If doc has a `note`, `free_text.anonymize(text)` runs Presidio `AnalyzerEngine` for entities `PERSON, PHONE_NUMBER, US_SSN, EMAIL_ADDRESS, DATE_TIME, LOCATION, US_DRIVER_LICENSE` and `AnonymizerEngine` replaces matches with `<PERSON>`, `<PHONE>`, etc.
4. `policy.allowed_fields(role)` returns `None` (all fields) in the POC. The `role` param is threaded through but unused — production adds a real map here without touching tool code.
5. Redactor returns `(redacted_doc, stats)` where `stats = {entities_redacted: {PERSON: 2, ...}, fields_dropped: [...]}`.
6. `audit.write_event(tool, args, hit_ids, stats, latency_ms)` — JSONL line, no PHI in audit.

## Agent UI flow

**Routes**: `GET /` (chat page), `POST /chat` (HTMX, returns HTML fragment), `GET /healthz`.

**Lifespan startup**: spawn MCP server subprocess via `mcp.client.stdio.stdio_client`, call `session.list_tools()`, convert MCP schemas → Anthropic `tools` format (near 1:1).

**Per-request loop in `agent.py`**:
1. Append user message to session history.
2. `anthropic.Anthropic().messages.create(model, tools, messages, max_tokens=1024)`.
3. If `stop_reason == "tool_use"`: for each `tool_use` block, call MCP via `session.call_tool(name, args)`, append `tool_result` content block to history, loop back to step 2. **Cap iterations at 6.**
4. If `stop_reason == "end_turn"`: render `_message.html` fragment with user bubble, assistant bubble, and collapsible tool-calls panel; return.

**Session state**: `InMemorySessionStore` (interface + `dict[str, list[Message]]` impl). Swap to Redis later.

**Templates**: `base.html` loads HTMX 2.x, has a `#chatlog` div and a form with `hx-post="/chat" hx-target="#chatlog" hx-swap="beforeend"`. `_message.html` renders one user+assistant turn.

## Verification runbook

1. Install Docker Compose plugin (`docker` is **not** on PATH currently — `sudo apt install docker.io docker-compose-plugin` then add self to `docker` group).
2. `sudo sysctl -w vm.max_map_count=262144` (ES 8 refuses to start otherwise).
3. Install `uv`: `curl -LsSf https://astral.sh/uv/install.sh | sh`.
4. `uv sync` (creates `.venv`, installs deps from lock).
5. `uv run python -m spacy download en_core_web_lg` (~560 MB — fall back to `en_core_web_sm` if bandwidth-limited).
6. `cp .env.example .env`, paste real `ANTHROPIC_API_KEY`.
7. `docker compose up -d`; wait ~30 s; `curl localhost:9200/_cluster/health` → yellow/green.
8. `uv run seed-es` → expect "Indexed 500 patients, ~1800 encounters".
9. `uv run agent-ui` → uvicorn on `:8000`. **Do not use `--reload`** (orphans MCP subprocess).
10. Open `http://localhost:8000` and verify the **money-shot demo**:
    - "Show me the note for encounter ENC-000042"
    - UI shows redacted note with `<PERSON>`, `<PHONE>` tokens
    - `curl localhost:9200/encounters/_doc/ENC-000042` directly still shows real PHI — confirming **the model never received it**
    - `audit/YYYY-MM-DD.jsonl` shows `redaction_stats.entities_redacted.PERSON >= 1`

## Out of scope for the POC (production add-ons)

TLS on ES/FastAPI · real authn/authz · role-based field allow-lists (interface present, single `default` policy) · persistent / tamper-evident audit · BAA-grade infra (encryption-at-rest, KMS, network isolation) · rate limiting · prompt-injection defenses on note text · all 18 Safe Harbor identifiers (POC hits ~10) · re-identification risk analysis.

## Risks to watch

- **Presidio + spaCy model size**: `en_core_web_lg` is ~560 MB; document `en_core_web_sm` fallback.
- **ES Docker memory**: pin `ES_JAVA_OPTS=-Xms1g -Xmx1g` and `mem_limit: 2g`; check `docker stats` if seeding hangs.
- **`vm.max_map_count`**: ES will refuse to boot without `262144` on Linux.
- **Anthropic tool-use loop pitfalls**: must append the `assistant` message containing the `tool_use` block *before* the `user` message with `tool_result`; `tool_result.content` must be a string or content-block list (JSON-stringify MCP responses); cap iterations to avoid infinite loops.
- **MCP stdio lifecycle**: `uvicorn --reload` orphans the subprocess; disable reload or wire `atexit` + lifespan shutdown carefully.
- **Model name drift**: if Anthropic returns 404 on `claude-sonnet-4-6`, change in `.env` only.
